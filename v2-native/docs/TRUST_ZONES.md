# 信任区基线

版本：1.0｜日期：2026-09-05｜性质：访问边界，失败关闭

本文只定义数据域、身份、AI、设备、备份与日志允许看见什么。阶段范围见 `PHASE0_SCOPE.md`；平台决策见 `DECISIONS.md`；金额如何入账见 `FINANCE_RULES.md`。V2 实现尚未开始；下列规则约束未来实现与现阶段文档，不描述旧 WebView 运行时已经做到什么。

默认原则：**未授权即拒绝。未知字段即拒绝。不能证明已持久化即不得声称已执行。**

旧运行时 `android/` 保持不动。不得把旧桥接、WebView 里的 `localStorage` 或 JS 上下文当作 V2 的信任区实现。

## 1. 四个信任区

统一界面不等于统一明文。健康、财务、普通生活、密钥必须分开授权、分开最小上下文、分开导出策略。

| 区 | 例子 | 默认存储 | AI | 设备终端 | 业务备份 | 全局搜索 |
|---|---|---|---|---|---|---|
| A 普通生活 | 任务、日程标题与时间、非敏感备注、专注计时 | 本机业务库 | 按当前会话授权给最小字段 | 默认可看下一件事标题与时间；敏感备注默认不发 | 可纳入加密业务备份 | 可 |
| B 健康 | 步数、睡眠、心率、压力、身高体重、来源区间 | 本机；来源与单位保留 | 默认摘要；非诊断；关闭权限后下次请求必须重过滤 | 仅展示用户允许的摘要 | 可纳入；原始健康库不作为 AI 数据源 | 可，不含原始波形 |
| C 财务 | 账户、凭证、往来、报表、投资估值 | 本机；命令写入 | 最小化汇总或有界子集；模型不算权威余额 | 不可直接入账；最多生成待确认草稿 | 可纳入；排除完整卡号 | 可，分组并带来源日期 |
| D 密钥库 | 密码、OTP、API Key、私钥、助记词、恢复码、卡安全码 | 独立策略；不与业务库混导出 | **永久不可访问** | **永久不可读** | **禁止随业务备份暗中导出** | **明文不可搜索** |

笔记和备注可能误含密钥。出站到模型之前必须做补充脱敏；脱敏失败则整请求拒绝。正则不能识别全部秘密，因此 D 区对象根本不进入工具数据源，而不是“脱敏后再发”。

## 2. 身份与权限

- 权限身份由本机应用会话或已绑定设备会话决定，不信任命令 payload 自报的角色。
- 财务、健康、日程、记忆分别授权；默认最小摘要。
- 关闭某一权限后，必须同时过滤：下一次模型请求、历史消息拼装、磁盘上的上下文缓存。只改 system prompt 里的一句话不算撤回。
- 模型供应商一旦收到内容，本机撤回权限不能从对方撤销。界面必须如实写“数据会离开手机”，禁止“从未离开”的假本地文案。
- 网页演示若出现，只说明原生能力；不得提供实际上不能工作的 AI 配置表单。

失败关闭：

| 条件 | 行为 |
|---|---|
| 未配置外部 AI | 可用本机规则；明确外部 AI 未连接 |
| 权限未授予或已撤回 | 对应区字段不进入上下文；不静默改用缓存旧摘要 |
| 无网络 / 限流 / 认证失败 | 分原因展示；不把等待说成已回答 |
| schema 外字段、非法 JSON | 整次工具调用拒绝 |
| 无法解析到唯一业务对象 | 要求用户选择，不擅自执行 |
| 设备未绑定、已解绑或会话过期 | 拒绝事件；已入库历史只保留来源记录 |

## 3. AI 工具边界

允许的第一批目标能力（均未实现，仅划界）：解释本月消费、查今日待办、生成记账/日程草稿、解释未结往来、对来源明确的健康记录做非诊断摘要。

| 允许 | 禁止 |
|---|---|
| 只读查询走本机查询服务 | 模型持有数据库句柄 |
| 写入只产生 proposal / 收件箱草稿 | 付款、证券或币交易、直接改库 |
| 预览将影响的对象与字段 | 读取 D 区；把推测写成事实 |
| 有限轮只读工具后终止 | 无限代理循环 |
| 数字附查询参数与时间窗口 | 模型自己 reduce 数组当余额 |
| 相对日期在请求时刻与时区解析，确认页显示绝对日期 | 仅凭“刚才那个”在多候选时自动改期 |

流程：输入 → 按权限建最小上下文 → 候选工具 → 严格 schema → 解析对象 → 本机预览 → 用户确认 → 命令执行 → 展示回执。

“已执行”只能来自命令回执，且必须能跳到真实实体。迟到的已取消响应必须丢弃副作用。

重试复用请求身份；新的独立用户请求保留独立身份。不能靠相似文本合并两笔真实需求。

## 4. 设备终端

首款目标是常供电桌面终端，经 BLE 连接 Android。板型未定，见决策日志 Q-11。

设备事件路径：鉴权 → 持久化 → 去重 → 领域处理。回执：

| 回执 | 何时允许发出 |
|---|---|
| accepted | 事件已在手机可靠持久化之后 |
| pending_confirmation | 需要用户确认（含财务草稿） |
| executed | 对应命令事务提交之后 |
| rejected | 鉴权失败、越权、冲突、容量满等 |

同一 eventId 到达 100 次，最多一个业务结果。sequence 只用于会话内排序，不能当跨重启主键。

设备禁止：

- 保存 AI Key、银行卡全号、密码库内容。
- 直接写已入账表。
- 在失联时把过期日程快照说成实时；必须显示“最后同步于 …”。
- 队列满时静默丢弃财务候选；必须拒绝或提示容量。

## 5. 捕获、通知与导入

通知捕获、文件导入、旅行解析、健康导入都属于适配器。它们只准写入收件箱或专用导入命令，不准写已入账表。

- 支付通知不是银行正式流水。
- 同一真实支付事件跨通知与无障碍通道只形成一条待确认项。
- 两次真实的同金额消费不得自动合并。
- OCR / 通知缺字段时保持待确认，禁止填默认 08:00 并显示为已确认。
- 健康导入按批次与来源记录 ID 幂等；多来源同一指标禁止无依据相加。

## 6. 备份、导出、日志

| 通道 | 允许 | 拒绝 |
|---|---|---|
| 加密业务备份 | 版本清单、一致性快照、附件索引、恢复元数据 | 密钥、密码明文、API Key |
| CSV 报表 | 用户选择的账本/任务导出 | 当作完整恢复格式 |
| 诊断包 | 错误码、耗时、匿名请求 ID、清理后的轨迹 | 健康原文、完整提示词、完整卡号、密码、Key |
| 审计事件 | 来源、动作、对象、结果、时间 | 密钥与敏感原始内容 |
| 通知与截屏 | 必要标题 | D 区明文；财务详情按系统可见性收敛 |

备份口令与业务库分离。密码库禁止随业务备份一起导出。恢复必须先入临时库，校验失败则保留当前库。

本机沙箱与系统磁盘加密 ≠ Room 已做整库应用级加密。未单独验收前，设置文案必须按实际保护范围书写。

## 7. 密钥与供应商

- AI Key 与密码库使用不同 Keystore 别名；方案本身仍须独立验证（决策 Q-05、Q-06）。
- 密钥不出现在日志、导出、ESP32、模型上下文、文档示例。
- 对外发送前用户可查看主机、数据类别和摘要范围。
- 无真实 token 上限、超时与取消配置时，不得对外部模型发请求。

文档与示例只写“已配置 / 未配置”，不写密钥形状、口令或证书材料。

## 8. 验收探针（文档层）

实现阶段必须能回答“否”即失败，而不是用免责声明代替：

1. D 区对象能否出现在任一 AI 请求体、设备消息、CSV、诊断包？必须不能。
2. 撤回健康权限后，下一条请求是否仍带上一轮健康摘要？必须不能。
3. 设备按键能否在无手机确认时增加一笔已入账支出？必须不能。
4. 模型返回“已转账成功”但命令未提交时，界面能否显示已执行？必须不能。
5. 未授权或未知工具字段是否被丢弃后继续执行？必须整单拒绝。

阶段 0 只冻结上述探针。通过这些探针的代码、测试和实机结果都不存在于本工作区。
