# 阶段 0 线框

非可运行 UI。用于确认信息架构。视觉：近白 `#F2F2F7`、白表面、克制薄荷绿、正文 ≥16sp、核心触控 ≥48dp、支持 200% 字体与读屏。

状态统一：loading / empty / ready / saving / failed。保存成功只来自事务结果。

## 全局

```
[头像/设置]  Self Agent          [收件箱 n]
--------------------------------
大标题
单一主动作
分组列表 / 卡片
--------------------------------
今天 | 账本 | 生活 | 助手
```

- 首页不露完整账户列表、汇率、设备排障、模型配置。
- 空状态引导第一条真实记录，不默认演示数据。
- 滑动动作必须有可见按钮替代。
- 金额用等宽数字并保留币种；负号不只靠颜色。
- 密码明文不进全局搜索。

## 今天

回答：现在最需要处理什么？

1. 下一件事（标题、时间、来源）
2. 今日至多三项重点
3. 待确认（最多 3 张，更多进收件箱）
4. 可选健康摘要（权限开且有今日数据；旧值标“最近一次，X 天前”）

主动作：完成任务 / 快速记录
空：还没有今天的安排。添加任务或同步日程。
失败：不能把过期快照说成实时。

## 账本

回答：钱和往来现在怎样？

1. 净资产 + 估值完整性（缺汇率则“部分估值”）
2. 本月个人消费、收入、往来待办
3. 最近流水
4. 账户入口、往来入口（各一处）

主动作：记一笔
不在此维护汇率（设置/估值详情）。

### 记一笔（普通支出一页）

金额 → 账户（账户决定币种）→ 分类；用途可选；日期默认业务当天。
“更多”：拆分、垫付、附件、备注。
换汇与往来走专用流程。
提交前本机校验；saving 禁止重复点；成功给撤销入口；失败保留全部输入。

## 生活

按使用频率：日程、任务、健康、行程。各模块自己的创建入口。

健康首屏：今日状态 → 7 日趋势 → 核心指标。资料与数据管理折下。缺日不补 0。睡眠显示 X小时Y分钟。Health Connect / Gadgetbridge / 导入排障 分入口。禁止健康分、BMI 巨数字、医疗诊断。

## 助手

对话、引用、动作预览、执行结果。
能力状态条必须真实。草稿待确认展示将改的对象与字段。已执行跳转实体。

## 收件箱

草稿、冲突、解析失败、执行失败。
操作：修改后确认 / 忽略。版本不符则冲突，不静默覆盖。

## 设置

权限、AI、备份、设备、隐私、审计。每项具体动作，不堆说明书。

## 十场景走查

| # | 入口 | 主路径 | 成功反馈 |
|---|---|---|---|
| 1 | 今天 | 打开应用 | 只突出下一件事与待确认 |
| 2 | 账本或通知 | 记 30 / 确认草稿 | 流水、余额、消费同时变 |
| 3 | 记一笔→更多垫付 | 300=100+200 | 三个数字可解释 |
| 4 | 往来 | 收回 120 | 剩余应收 80，不算工资 |
| 5 | 助手 | 问未做完 | 列出真实任务，无虚构评分 |
| 6 | 账本离线 | 记账 | 已保存；AI 显示不可用 |
| 7 | 账本 | 信用卡消费+还款 | 消费一次，欠款变化正确 |
| 8 | 账本 | 转账 | 净资产不变 |
| 9 | 流水 | 冲销 | 原记录在，已更正 |
| 10 | 设置→助手 | 关健康摘要再问 | 回答不含健康数据 |

## 无障碍与极端

每个组件需覆盖：浅色、深色、超长中文、200% 字体、读屏、键盘不挡提交。核心操作 48dp。不在整张可点卡片内嵌另一按钮。
