# 阶段 0 线框

性质：**纸面信息架构**，不是可运行 UI，不是视觉定稿，更不是 Compose。实现从用户确认后的 `U-01` 起算。

口径与分录只在 `FINANCE_RULES.md`。信任区失败关闭只在 `TRUST_ZONES.md`。本文只规定：四栏怎么走、主动作在哪、五态怎么说、触控与读屏怎么验。视觉方向：近白 `#F2F2F7`、白表面、单一克制强调色（薄荷绿）、正文 ≥16sp。

状态统一：`loading` / `empty` / `ready` / `saving` / `failed`。保存成功只来自事务结果。

---

## 1. 全局骨架

```
┌──────────────────────────────────────┐
│ [头像 48dp]  大标题          [铃铛 48dp]
│                            未处理 n   │
│ …………………… 内容区 ……………………   │
│                                      │
├──────────────────────────────────────┤
│  今天     账本     生活     助手     │  ← 每项 ≥48×48dp
└──────────────────────────────────────┘
```

| 入口 | 回答的问题 | 单一主动作 | 首页禁止堆 |
|---|---|---|---|
| 今天 | 现在最需要处理什么？ | 完成任务；次操作「快速记录」 | 完整账户列表、汇率、设备排障、模型配置 |
| 账本 | 钱和往来现在怎样？ | **记一笔** | 投资写入（核心版关闭） |
| 生活 | 日程、健康和资料在哪？ | **按模块创建** | 把导入排障当默认首屏 |
| 助手 | 帮我理解或准备一个动作 | **提问／发起草稿** | 把未配置 AI 写成已回答 |
| 收件箱（顶栏） | 哪些还没确认？ | **修改后确认** | 直接写入已入账表 |
| 设置（头像） | 数据和设备由谁控制？ | 该项的具体设置 | 密码明文、API Key |

- 空状态引导第一条**真实**记录，不默认演示数据。
- 滑动动作必须有可见按钮替代。
- 密码明文不进全局搜索、不进读屏明文。
- 系统返回：浮层/详情弹出；四栏替换根；仅稳定「今天」且无浮层时结束应用。

## 2. 触控、200% 字体、读屏

| 规则 | 要求 |
|---|---|
| 触控 | 核心操作命中区 **≥48×48 dp**。整张可点击卡片内不得再嵌另一个按钮；确认/忽略/编辑/冲销走独立芯片行。 |
| 间距 | 4/8/12/16/24/32 dp；页边 16–20 dp。 |
| 字体 | 平台中文；正文 16 sp，辅助 13–14 sp。跟随系统缩放。 |
| 200% | 大标题与金额换行，不横向裁切；底栏可改为图标 + `contentDescription`；主按钮仍完全可见且 ≥48 dp；键盘不得挡住提交与错误原因。 |
| 读屏 | 金额读「币种 + 符号 + 数值」，不只靠红绿。五态用 `liveRegion`。 |
| 金额 | `MoneyText`：等宽数字、保留币种、负号与文字说明并存。零就是 0.00，缺失就是缺失。 |
| 组件态 | 每个组件需能画：浅色、深色、超长中文、200% 字体、读屏标签。 |

组件库（`U-01` 才建）：PageScaffold、Section、MoneyText、AccountRow、LedgerRow、DraftCard、StatusMessage、EmptyState、ErrorState、DateSelector、ConfirmationSheet。

### 五态文案（所有可写页）

| 态 | 视觉 | 读屏 |
|---|---|---|
| loading | 骨架或「正在读取本机数据」，无假数字 | 「正在加载」 |
| empty | 一句引导 + 主动作；净资产空为 `0.00` | 下一步可做什么 |
| ready | 真实查询结果 | 标题、金额、来源、日期 |
| saving | 主动作变为「保存中」且不可再点；保留已填字段 | 「正在保存」 |
| failed | 保留全部输入 + 可读原因 + 重试 | 朗读原因，不说「系统异常」 |

断网：本机命令仍可提交；外部 AI / 行情显示不可用，不得写成已执行。

## 3. 今天

主动作：**完成**（针对下一件事）。次操作：标题行「快速记录」。待确认最多 3 张，更多进收件箱。

```
┌──────────────────────────────────────┐
│  SA          今天            铃铛 2  │
│  星期几 · 数据更新于 07:10           │
│                                      │
│  下一件事                            │
│  ┌────────────────────────────────┐  │
│  │ 12:20  午饭后散步              │  │
│  │ 健康 · 20 分钟                 │  │
│  │          [ 完成  48dp ]        │  │
│  └────────────────────────────────┘  │
│                                      │
│  今日重点（至多三项）                 │
│  · 整理季度预算  15:00               │
│  · 给妈妈打电话  19:30               │
│                                      │
│  待确认                              │
│  ┌────────────────────────────────┐  │
│  │ 微信支付  36.00 CNY  候选      │  │
│  │ 来源：通知 · 今天 12:31        │  │
│  │ [修改后确认]     [忽略]        │  │
│  └────────────────────────────────┘  │
│                                      │
│  健康摘要（权限关则整块消失）         │
│  睡眠  6小时12分 · 今日              │
│  旧值标「最近一次，X 天前」，不标今天  │
│                                      │
│              [ 快速记录 48dp ]       │
└──────────────────────────────────────┘
```

- **empty**：「还没有今天的安排。」主按钮「快速记录」或「添加任务」。
- **loading**：三块骨架，无金额占位。
- **saving**：完成按钮「保存中」；失败则该条仍未完成。
- **failed**：「今天无法刷新。本机数据未丢失。」禁止把过期快照说成实时。

## 4. 账本

主动作：**记一笔**。总览先净资产及估值完整性，再本月个人消费、收入、往来待办。往来管理入口只有一处；首页/助手卡片只跳转同一记录。汇率不在本页维护。

```
┌──────────────────────────────────────┐
│  账本                        铃铛    │
│                                      │
│  净资产                              │
│  CNY  12,340.55                      │
│  已知部分估值 · 2 笔 USD 未折算      │  ← 缺汇率绝不 1:1
│                                      │
│  本月（个人消费口径，不是现金流）     │
│  消费 …    收入 …                    │
│                                      │
│  往来待办                            │
│  应收 …    应付 …     [查看往来]     │
│                                      │
│  最近流水                            │
│  午餐   −36.00 CNY  微信  今天       │
│         [编辑] [冲销]                │  ← 可见，非仅滑动
│                                      │
│                 [ 记一笔  48dp FAB ] │
└──────────────────────────────────────┘
```

子页（全屏）：流水、账户、往来。投资在核心版显示「后续启用」，不可写入。

### 记一笔（普通支出一页，底部表单）

```
┌──────────────────────────────────────┐
│  记一笔                         关闭 │
│  金额 *   [ CNY            36.00 ]   │  ← 币种由账户决定
│  账户 *   微信余额 ▾                 │
│  分类     餐饮     ▾                 │
│  用途（可选）                         │
│  业务日期  今天              [改]    │
│  [更多] 拆分 · 垫付 · 附件 · 备注    │
│  换汇、往来走专用流程                 │
│  [ 保存 ]   saving 时禁用重复提交     │
└──────────────────────────────────────┘
```

金额空缺不能进预览。成功：短结果 + **撤销**（冲销命令，不是删 ID）。失败：保留输入 + 领域拒绝原因。

- **empty**：净资产 `0.00` +「添加第一个账户」。
- **loading**：总览骨架。
- **saving**：FAB 禁用。
- **failed**：查询失败条，不把上次缓存标成已刷新。

## 5. 生活

主动作：**创建**，先选模块（任务 / 日程 / 健康 / 行程），按使用频率排序。任务 ≠ 日程 ≠ 提醒：可关联，不复制成三条互不相关记录。

```
┌──────────────────────────────────────┐
│  生活                        铃铛    │
│  日程     今天 3 项                  │
│  任务     2 项待完成                 │
│  健康     睡眠已更新                 │
│  行程     无即将出发                 │
│                    [ 创建  48dp ]    │
└──────────────────────────────────────┘
```

健康首屏：今日状态 → 7 日趋势 → 核心指标。缺日留空、不补 0。睡眠显示 `X小时Y分钟`。Health Connect / Gadgetbridge / 导入排障分入口。禁止健康分、BMI 巨数字、医疗诊断。「今天」只展示今天数据。行程缺字段保持「待确认」，禁止默认 08:00 冒充已确认。

权限未开：健康卡变为「未授权，去设置」，不是假零。

## 6. 助手

主动作：**提问**。模型只产草稿；数字必须引用查询结果。

```
┌──────────────────────────────────────┐
│  助手                        铃铛    │
│  状态：未配置外部 AI · 可用本机规则   │
│  范围：财务关 · 健康关 · 日程开       │
│                                      │
│  ┌ 对话 ──────────────────────────┐  │
│  │ 依据必须带实体 ID，不是评分     │  │
│  └────────────────────────────────┘  │
│                                      │
│  待确认草稿                          │
│  ┌────────────────────────────────┐  │
│  │ 将影响：账户、本月消费          │  │
│  │ [确认执行] [编辑] [丢弃]        │  │
│  └────────────────────────────────┘  │
│  [        提问或描述一件事        ]  │
└──────────────────────────────────────┘
```

能力条必须真实：未配置 / 测试通过（含时间、主机、模型）/ 请求中可取消 / 无网络·限流·认证失败分原因 / 仅本机回答 / 草稿待确认 / 已执行·冲突·拒绝来自命令回执。不允许在助手内付款、改库、读密码库。

## 7. 收件箱

从铃铛进入。主动作：**修改后确认**。候选不得先写入已入账表。

```
┌──────────────────────────────────────┐
│  ← 收件箱                             │
│  待处理 · 冲突 · 解析失败 · 执行失败  │
│  ┌ DraftCard ─────────────────────┐  │
│  │ 来源 / 置信 / 金额 / 可改账户   │  │
│  │ 跨通道同一支付已合并为此条      │  │
│  │ [确认] [忽略]                   │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

版本不符 → 冲突，不静默覆盖。并发双击同一 commandId 只入一次。忽略不写账本。两笔真实同额消费不得自动合并。金额缺失不能确认。

## 9. 十个关键场景走查（出关锁）

下列编号与 `PHASE0_SCOPE.md` S1–S10、`FINANCE_RULES.md` 一致。本文只走**页面路径与反馈**；分录以财务规则为准。任一口径冲突则阶段 0 不出关。

日常闭环（不另开口径）：早上打开今天、买午餐手动或通知草稿、晚上按真实任务复盘、断网本机提交成功且外部能力显示不可用。

### S1 工资入账

1. 账本 → 记一笔（收入）→ 金额、资金账户、分类「工资」。
2. saving 禁用重复点。成功：流水显示收入、净资产增加；助手若引用须走同一查询。
3. 不得出现在「报销收回」入口。失败：无账户则留在表单。

### S2 资金账户消费（买午餐）

1. 账本 → 记一笔，或今天/收件箱确认支付草稿。
2. 成功：流水、该账户余额、本月**个人消费**同时变。
3. 通知候选在确认前不算消费。金额空缺不能确认。

### S3 同币种转账

1. 记一笔不兼任；走「转账」专用流程：来源账户、目标账户、金额。
2. 成功：两边流水可见；净资产不变；不算收入或消费。
3. 同账户转账、币种不匹配：failed 保留输入。

### S4 信用卡消费

1. 账户选信用卡 → 记支出。
2. 成功：算个人消费、欠款增加；**不是**资金账户现金流出。
3. 读屏区分「欠款增加」与「现金减少」。

### S5 信用卡还款

1. 账户详情或专用「还款」：还多少 + 哪个同币种资金账户（禁止暗用默认账户全额）。
2. 成功：不重复算消费；资金流出；欠款减少。溢缴款展示在资产侧，不截成 0 仍写「欠款」。
3. 与 S4 在同一账户时间线可连续走查。

### S6 垫付拆分

1. 记一笔 → 更多 → 垫付：实付 300 = 个人 100 + 垫付 200。
2. 成功反馈三个可解释数字（消费 / 应收 / 资金流出）。
3. 两数之和 ≠ 实付 → 拒绝，表单不清空。

### S7 部分报销收回

1. 账本 → 往来（唯一入口）→ 收回 120 + 同币种资金账户。
2. 成功：资金 +120，应收剩余 80，**不算工资/本月收入**。
3. 超额拒绝。跨币种核心版入口说明「后续开放」且不可提交。

### S8 借入与还本息

1. 借入：资金增加、应付增加，不算收入。
2. 还本金 + 利息：本金走往来，利息走费用/消费；界面分两行金额，禁止一个框算完。
3. 失败：缺应付事项或金额拆不开则拒绝。

### S9 真实退款 vs 冲销 vs 更正

1. 流水行可见「冲销」「更正」；退款走关联原消费的专用流程。
2. 冲销成功：原记录仍在，状态已更正/已冲销，余额含两者。再次冲销返回既有结果。
3. 退款归属退款日，不把原消费事件抹掉。三入口不得合成一个「删除」。

### S10 余额校正与缺汇率

1. 校正：显式命令 + 必填理由；成功不进收入/消费报表。
2. 净资产区：缺汇率显示「已知部分估值 + 未折算明细」，禁止把 USD 按 1:1 加进 CNY。
3. 非法金额/JPY 小数：记一笔 failed，字段仍在。

## 10. 无障碍抽查（六页都要过）

1. 200% 下主按钮仍 ≥48 dp、不被底栏或键盘挡住。
2. 底栏读屏顺序：今天 → 账本 → 生活 → 助手。
3. DraftCard 确认/忽略不是整卡点击的一部分。
4. 长中文商户名换行，金额不被挤出。
5. 深色模式对比足够；正负不独靠颜色。
6. 设置里权限状态与 `nativeReady` 式桥接就绪无关。
